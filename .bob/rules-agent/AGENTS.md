# Project Coding Rules (Non-Obvious Only)

## Frontend (repo root)

- **Never touch `src/routeTree.gen.ts`** — it is fully regenerated by TanStack Router on every dev/build run. Edits are silently overwritten.
- **Adding a route**: create a new `.tsx` file in `src/routes/`. Filename IS the URL. Dynamic params use `$param` (bare dollar, no curly braces). See [`src/routes/README.md`](../../src/routes/README.md).
- **Do NOT duplicate plugins in `vite.config.ts`**: `@lovable.dev/vite-tanstack-config` already bundles TanStack devtools, `viteReact`, `tailwindcss`, `tsConfigPaths`, Nitro, and others. Adding any of these again breaks the build silently.
- **Server-only modules**: name the file `*.server.ts` or annotate with `@tanstack/react-start/server-only`. The `server-only` npm package (Next.js) is banned by ESLint rule.
- **Tailwind design tokens** are in [`src/styles.css`](../../src/styles.css) under `@theme inline` — there is no `tailwind.config.*`. Brand colors: `--sand`, `--blush`, `--terracotta`. Fonts: `font-display` (Marcellus) for headings, `font-body` (Jost) for body.
- **`cn()` is the only approved class-merging utility** ([`src/lib/utils.ts`](../../src/lib/utils.ts)) — never concatenate class strings directly.
- **shadcn/ui** components: add with `npx shadcn add <name>`, they land in `src/components/ui/`. Site-specific components go in `src/components/site/`.
- **Error reporting** goes through [`src/lib/error-reporting.ts`](../../src/lib/error-reporting.ts) `reportError()` (client-only — guards `typeof window === "undefined"`). SSR errors are captured via [`src/lib/error-capture.ts`](../../src/lib/error-capture.ts) which patches `console.error` globally on import.
- **CSRF**: `createCsrfMiddleware` in [`src/start.ts`](../../src/start.ts) must stay; removing it re-exposes server functions to CSRF attacks. TanStack only auto-installs it when `src/start.ts` is absent.

## Backend (`vedaarna-medusa/`)

- **`medusa-config.js` must stay CommonJS** (`module.exports = { ... }`). Do NOT convert to ESM. Medusa v2 loader requires it.
- **Modules are a keyed object**, not an array. Wrong format = silent startup failure.
- **Admin is disabled** — do not add admin-only dependencies or routes that assume the admin panel is running.
- **`src/links/` directory**: create link files here to declare cross-module relationships. Currently empty — the log `No link to load` is normal.
- **JWT/Cookie secrets**: fall-through defaults in `medusa-config.js` are for local dev. Production MUST set `JWT_SECRET` and `COOKIE_SECRET` in the environment — missing `JWT_SECRET` causes the repeated `Error starting server` crash in the provided logs.
- **`sharedContainer` resolution error** in logs = a service references a module not registered in `medusa-config.js`. Fix: add the missing module to the `modules` keyed object.
- **Tests**: Jest + `@swc/jest` with TypeScript decorator support. Run single test: `npx jest --testPathPattern=<file>` from `vedaarna-medusa/`.
- **Seed script path**: hardcoded to `src/scripts/seed.ts` in `package.json`. Create it there.
